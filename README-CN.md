## 介绍

AiTrainer是一款结合人工智能机器视觉的智能健身系统，使用谷歌开源的移动端机器学习套件 [ML Kit](https://developers.google.cn/ml-kit) 结合 BlazePose 神经网络模型进行实时人体关键点检测，通过Mediapipe进行人体姿态估计。通过智能健身系统可以获取自身健身情况（动作标准度，动作完成度，卡路里消耗等）。同时，智能健身系统为用户提供具体的健身方案和对健身动作的评价，帮助用户更加高效地健身。
